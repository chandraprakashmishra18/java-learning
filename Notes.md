JVM :
    JVM stands for "Java Virtual Machine".
    It is the software that runs Java programs. Instead of Java code running directly on your computer’s operating system, Java is compiled into bytecode, and the JVM executes that bytecode.
    Basic flow:
    Java source code (.java) → Java Compiler (javac) → Bytecode (.class) → JVM → Program runs
    * Java is a platform independent language
